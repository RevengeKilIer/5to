## 🌟 Apartado Principal: Catálogo de Productos

El catálogo es la sección más destacada del sitio, permitiendo:
- **Filtros interactivos por categoría:** Ver todos los productos, leches, quesos/requesón y yogures.
- **Afiches de alta definición:** Visualización de las piezas gráficas oficiales del emprendimiento con visor modal/lightbox.

## 🚀 Cómo Ejecutar el Sitio Web

1. **Apertura directa:** Haz doble clic sobre el archivo `index.html` para abrirlo en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).
2. **Servidor local (Live Server):** Abre la carpeta en VS Code y pulsa en "Go Live" o "Open with Live Server".
